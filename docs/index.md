# Recipe Box

Recipe Box is a personal Android app for saving recipes. It imports a recipe
from a link, a shared note, or a photo of a recipe card. It scales ingredient
amounts, converts metric units to US units, and builds grocery lists.

Recipe Box isn't distributed through an app store. It has no server and no
accounts: recipes stay on the phone, and backups go to the user's own Google
Drive.
